# درباره این مخزن

This repository contains the Python examples, exercises and educational files created during the Python P6 course at Fanavari Tehran.

Each class session has a separate folder containing the related examples and practice files.

The repository helps students:

Review topics covered in class
Run and modify Python examples
Practice programming concepts
Follow their progress throughout the course
Become familiar with Git and GitHub
